# CarIntel Landing Page & Legal Hub

Diese Webseite dient als zentraler Hub für die **CarIntel** Chrome-Erweiterung und stellt die gesetzlich vorgeschriebene Datenschutzerklärung (DSGVO) sowie das Impressum bereit.

Sie wurde für ein kostenloses, sofortiges Hosting via **GitHub Pages** konzipiert, damit du schnell eine Live-URL für das Google Chrome Web Store Developer Dashboard erhältst.

## 🚀 GitHub Pages Aktivierung (in 3 Schritten)

### 1. Repository auf GitHub pushen
Lade den Ordner `landingpage/` (mit der `index.html`) auf GitHub hoch. 
Entweder du erstellst ein separates Repository (z.B. `carintel-landingpage`) oder du platzierst diese Dateien in deinem bestehenden Extension-Repository (z.B. im `main` Branch in einem Unterordner oder im `gh-pages` Branch).

### 2. GitHub Pages aktivieren
1. Gehe in deinem GitHub-Repository oben auf **Settings** (Einstellungen).
2. Klicke links im Menü auf **Pages**.
3. Wähle unter "Build and deployment" als Source **Deploy from a branch**.
4. Wähle den Branch (z.B. `main`) und den Ordner, der die `index.html` enthält (entweder `/root` oder `/landingpage`, je nachdem wie dein Repository strukturiert ist).
5. Klicke auf **Save**.

### 3. URL abrufen und eintragen
Nach wenigen Minuten ist deine Webseite online unter:
`https://<dein-github-name>.github.io/<dein-repo-name>/`

Kopiere diese URL und füge sie im **Chrome Web Store Entwickler-Dashboard** bei den Reitern für *Datenschutzrichtlinie* und *Website des Entwicklers* ein.
